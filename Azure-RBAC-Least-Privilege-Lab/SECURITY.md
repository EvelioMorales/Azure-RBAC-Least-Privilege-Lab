# Security and privacy notes

The screenshots in this repository are redacted copies prepared for public documentation. Personal names, user principal names, tenant-specific domains, subscription identifiers, account identifiers, and unrelated resource names were covered before publication.

Do not add unredacted Azure screenshots to this repository. Before committing a new image, check the portal header, breadcrumbs, account panels, resource identifiers, error details, URLs, downloaded filenames, and browser UI for identifying or sensitive information.

This project demonstrates authorization controls in a disposable lab environment. Never remove or reduce access on a production administrator account merely to reproduce the exercise.
